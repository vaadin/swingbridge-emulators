This page was loaded with setPage(URL) from the classpath. Clicking a link below does not navigate the browser: it fires a Swing HyperlinkEvent, and this demo's listener decides what it means — here, load the target page.

  • Topics — a second page

The link targets are http URLs on purpose. The editor's sanitizer keeps an href only for http, https and mailto, so a relative or file: href would be stripped and the link would render as plain text. A migrated help viewer therefore maps link URLs to its own resources in the listener, exactly as this demo does — nothing is fetched from the network.
